# Video to Audio

Client-side PWA that extracts audio from videos as M4A (stream copy), WAV (decode) or MP3
(LAME). FFmpeg runs as WebAssembly in a Web Worker; nothing is uploaded. Primary target is
iPhone Safari.

## Checks

- `npm run typecheck`: TypeScript 7, strict
- `npm test`: Vitest. `tests/unit` (pure logic) and `tests/core` (runs the real wasm core in
  Node and compares outputs against native ffmpeg/ffprobe, which must be on PATH)
- `npm run build`: Vite build into `dist/`, including the generated `sw.js`
- `npm run test:e2e`: Playwright against `vite preview`, WebKit (iPhone 14 Pro Max) and Chromium (Pixel 7)
- `npx wrangler deploy --dry-run`
- `npm run check` runs typecheck, tests, build and e2e

## Deploy

Automatic: `.github/workflows/ci.yml` deploys `main` to Cloudflare Workers static assets
(`video-to-audio.reloru.workers.dev`) after all checks pass, then verifies the live `sw.js`
hash matches the build. Manual fallback: `npm run deploy`.

## Conventions

- `core/dist/` is a committed build artifact of `core/build.sh`. Never edit it by hand; change
  `core/build.sh`, `core/probe.c`, `core/bind.js` or `core/patches/` and rebuild. Keep
  `core/dist/ffmpeg-core.d.ts` (hand-written) in sync with `src/engine/core.ts`.
- The patched fftools end every run with `abort()`, so each probe/convert uses a fresh module
  instance (`createCore`). Don't reuse an instance after `exec`.
- Any ffmpeg component the planner relies on must be enabled in `core/build.sh`; the CLI fails
  only at runtime otherwise. Cover new output paths in `tests/core`.
- All output args strip metadata (`-map_metadata -1 -map_chapters -1 -fflags +bitexact`).
  Tests assert no `udta/meta/ilst`, WAV with only `fmt `/`data`, MP3 without ID3.
- Decode paths trim to the container-declared length (`atrim=end_sample`) only for the
  QuickTime/MP4 demuxer, whose stream duration comes from the edit list.
- Test fixtures are generated by `tests/fixtures/generate.sh`; regenerate rather than hand-edit.
- `?output=memory` forces in-memory outputs (used by e2e; fallback if OPFS misbehaves).
